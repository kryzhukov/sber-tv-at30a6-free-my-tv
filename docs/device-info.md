# Телевизор: полная модель и свойства

**SaluteTV (Сбер ТВ) AT30A6** — 43″, Amlogic T5W/T962D4, 2 ГБ ОЗУ, Android 13 (StarkOS, сборка `TP1A.220905.004.A2` / `eng.tuz_st.20260618.150425`), панель `LE43VA_V430DJ1_Q01_D2_WDX_MS`, плата CVTE `ro.cvte.model=MD_CVTE_OVERSEA_T962D4_13_0_D18D20_2GB_STARKOS`.
Загрузчик залочен (`verifiedbootstate=green`), dm-verity выключена (`veritymode=disabled`), adbd слушает 5555 (`service.adb.tcp.port=5555`), `ro.adb.secure=1`.

Как получить это самому:

```powershell
$adb = "C:\platform-tools\adb.exe"
& $adb connect <IP-ТВ>:5555
& $adb shell getprop
& $adb shell "cat /proc/device-tree/model"
& $adb shell "dumpsys package io.freemytv | Select-String versionName"
```
