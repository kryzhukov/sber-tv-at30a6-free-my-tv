## 1. Как пользоваться главным экраном

- **Стрелки + ОК** — навигация по полке.
- **Сверху справа**: «Телеканалы» (открывает родное Сбер-ТВ с антенной; если каналы не настроены — предложит «Настроить»), «Входы HDMI», «Настройки» Free My TV.
- **Снизу**: «Телеканалы», HDMI 1–3, **«Приложения»** (все программы), «Главный экран» (переключение режима; «Заводской» больше не вернёт Сбер — лаунчер удалён), «Настройки ТВ».
- **Добавить/убрать приложение с полки**: «Приложения» → встать на приложение → **удерживать ОК**.
- **Настройки Free My TV**: «Приложения» → Free My TV (или шестерёнка сверху справа): язык, город, тема, °C, избранные приложения, верхние кнопки, кнопки пульта.
- Кнопка **«Домой»** возвращает на Free My TV из любого приложения.
- Заставка: если долго ничего не нажимать, включается заставка Free My TV (фото + часы).

## 2. Что удалено (не просто отключено)

Удалено для пользователя командой `pm uninstall --user 0`: приложение пропадает из системы (из «Приложений», из лаунчера, его нельзя запустить), данные стираются. Для системных разделов (`/vendor`, `/system`) сам APK остаётся в прошивке — такое приложение можно вернуть командой `cmd package install-existing --user 0 <пакет>`. Приложения Сбера, которые лежали в пользовательском разделе (`/data`), удалены полностью — вернуть их можно только сбросом ТВ или переустановкой от Сбера.

Плюс `com.spocky.projengmenu` (Projectivy Launcher) удалён ещё раньше.

**Важно про лаунчер Сбера:** прошивка Сбера при **каждой загрузке** возвращает `ru.sberdevices.starlauncher` (он лежит в защищённом разделе прошивки). «Сбер-Стоп» удаляет его обратно в течение ~2 минут после загрузки; главный экран на это время остаётся Free My TV. Совсем «вырезать» его из прошивки без root нельзя — только так, сторожем.

**Вернуть системное приложение (если очень нужно):**

```powershell
$adb = "%USERPROFILE%\dsh-tv-build\platform-tools\adb.exe"
& $adb connect <IP-ТВ>:5555
& $adb shell "cmd package install-existing --user 0 ru.sberdevices.starlauncher"
```

**Важно:** «Сбер-Стоп» (раздел 4) увидит вернувшееся приложение и снова его удалит через несколько секунд. Чтобы вернуть надолго — сначала выключите сторожа:

```powershell
& $adb shell pm disable-user --user 0 io.sberstop   # выключить сторожа
& $adb shell "cmd package install-existing --user 0 <системный.пакет>"
& $adb shell pm enable io.sberstop                  # включить сторожа обратно
```

## 4. Чтобы мусор Сбера не возвращался сам

За это отвечают два сторожа сразу.

**1) Free My TV** после каждой загрузки (и после своих обновлений) проверяет режим: если Салют включил обратно лаунчер, заставку или приложения из списка — снова их отключает и возвращает себя главным экраном.

**2) Приложение «Сбер-Стоп» (`io.sberstop`, в «Приложениях» так и называется)** — отдельный сторож, который:
- запускается **после каждой загрузки** (задание на +45 секунд — фирменный лаунчер Сбера возвращается при каждой загрузке, и сторож снова его удаляет);
- дальше работает **фоновым заданием JobScheduler каждые ~2 минуты** (не службой с уведомлением — Android 13 запрещает запускать такие службы из фона, а задания — можно и надёжно);
- **удаляет** всё, что Сбер вернул (`pm uninstall --user 0`; если удалить нельзя — хотя бы `pm disable-user`);
- заново выставляет `ota_disable_automatic_update=1` и `auto_update_apps=0`;
- запрещает рекламный оверлей Сбера;
- если главным экраном оказался не Free My TV (Сбер вернул свой лаунчер или сбросил выбор) — возвращает главным экраном Free My TV.

Проверено на перезагрузках: после `adb reboot` Сбер возвращает свой лаунчер — сторож удаляет его обратно в течение ~2 минут, главный экран при этом остаётся Free My TV. Вручную восстановленный лаунчер Сбера сторож также удалил в течение пары минут.

Открыть: «Приложения» → **«Сбер-Стоп»**. Там видно, когда была последняя проверка и что заблокировано, и есть кнопка **«Проверить сейчас»**.
Первый запуск один раз спросит разрешение отладки — поставьте галочку «Всегда разрешать» (как и для Free My TV).

**Если хотите временно вернуть приложение Сбера** — сначала выключите сторожа, иначе он удалит его снова:

```powershell
& $adb shell pm disable-user --user 0 io.sberstop
& $adb shell "cmd package install-existing --user 0 ru.sberdevices.starlauncher"   # системное приложение
& $adb shell pm enable io.sberstop     # включить сторожа обратно
```

Плюс навсегда выставлено в настройках ТВ:

```powershell
& $adb shell "settings put global ota_disable_automatic_update 1"
& $adb shell "settings put global auto_update_apps 0"
```

Если Салют всё же что-то вернул: откройте «Сбер-Стоп» → «Проверить сейчас» (или просто подождите до 2 минут — сторож сам удалит), либо перезагрузите ТВ.

**Реклама поверх экрана.** Сбер умеет рисовать поверх всего полноэкранные промо («Звук», «Прайм» и т.п.). Запрещено оверлею службы Сбера:

```powershell
& $adb shell "appops set ru.sberdevices.services SYSTEM_ALERT_WINDOW deny"
```

Если вдруг перестанут показываться **визуальные карточки голосового ассистента** (сам голос работает) — вернуть:

```powershell
& $adb shell "appops set ru.sberdevices.services SYSTEM_ALERT_WINDOW allow"
```

**Рекомендация (сильнее любых настроек):** на роутере заблокировать для ТВ `myou.cvte.com` (OTA-сервер CVTE, прописан в системе как `ro.cvte.ota.url`) и домены обновлений Сбера. Тогда прошивка физически не скачается.

## 5. Пульт с телефона (Homuz)

Служба, которая принимает подключение Homuz, была **выключена** (видимо, её отключили при чистке). Сейчас включена:

```powershell
& $adb shell pm enable ru.sberdevices.gamepad.service
```

Что проверить, если телефон не подключается:
1. Телефон и ТВ в одной Wi-Fi сети (ТВ: «<Wi-Fi>», `<IP-ТВ>`).
2. Открыть на телефоне Homuz → выбрать ТВ → подключиться.
3. Смотреть логи ТВ:

```powershell
& $adb shell "logcat -d | Select-String GamepadService | Select-Object -Last 20"
```

Хорошие строки: `Registered gamepad session: ...`, не должно быть `Disconnect due to no pings after 5 seconds`.
NoDPI настроен так, что заворачивает в VPN только YouTube-приложения, поэтому пульту с телефона он не мешает.

## 6. YouTube: три клиента + ускоритель (сейчас отключён)

- **YouTube** (Google) — на полке, работает.
- **SmartTube 32.68** — установлен (без рекламы), на полке, работает.
- **СберTube** (`ru.sberdevices.startube`) — на полке, **работает**. Важно: у него внутри есть собственный SOCKS-прокси (Настройки → SOCKS прокси → «Вручную/Автоматически»), который на этом ТВ не запускается (порт `127.0.0.1:11081` не слушается), из-за чего приложение писало «Нет доступа к сервису YouTube». Сейчас там стоит **«Отключен»** — и СберTube ходит напрямую через роутер (у вас обход DPI на роутере). Если Сбер сбросит настройки и снова появится эта ошибка: СберTube → шестерёнка слева внизу → «SOCKS прокси» → **Отключен**.
- **NoDPI («ускоритель YouTube») 1.0.5** — поставили, но на этом ТВ он ломал все три YouTube-приложения: туннель поднимался, а трафик внутрь не проходил. По вашему указанию (обход DPI уже есть на роутере) **отключён**:
  - снят «всегда включённый VPN» (`always_on_vpn_app`);
  - приложение `org.nodpi.hello` выключено (`pm disable-user`), но не удалено.

  Включать обратно не нужно, пока на роутере работает обход DPI. Если когда-нибудь понадобится — сначала запустить NoDPI один раз (чтобы поднялся его прокси), потом включить пакет и `settings put secure always_on_vpn_app org.nodpi.hello`, и не удалять три YouTube-приложения (они прописаны в его whitelist).

## 7. Про смену прошивки на «чистый Android TV» — честно: нельзя

Коротко: **публичного способа поставить на этот ТВ другую ОС нет**, и это не «мы не нашли», а ограничения железа:

- **Загрузчик залочен** (`verifiedbootstate=green`, AVB работает). Патченый boot/recovery не загрузится. На Amlogic `fastboot flashing unlock` на user-прошивках обычно отвечает `locked device` / `unrecognized command`.
- **Публичных образов нет.** Для SaluteTV/Сбер ТВ нет ни Android TV, ни LineageOS, ни рабочего порта: есть только любительское TWRP-дерево `SKOCHE/SaluteTV_at30a6_TWRP` без релизов и инструкций (и с чужими параметрами платы) и сервисный eMMC-дамп (снимается паяльником/UART, только по регистрации на ремонтном форуме).
- **GSI не подойдёт архитектурно.** ТВ 32-битный (`armeabi-v7a`), а Google с Android 13 публикует GSI только ARM64/x86_64. Плюс GSI — «система без драйверов ТВ»: отвалятся тюнер (антенна), HDMI-входы, CEC, пульт, звук/панель, фирменные службы Сбера — вернуть без вендорских драйверов нельзя.
- **Восстановление только аппаратное.** Публичного recovery-образа/ключей нет: если что-то пойдёт не так — только разборка, UART/ISP и сервисный дамп. Риск кирпича высокий, выигрыш сомнительный.
- **Единственное официальное «перепрошить»** — восстановление **стоковой** прошивки с флешки (FAT32) по модели/месяцу выпуска: `sberdevices.ru/firmware_tv` и инструкция «Переустановить прошивку» на `sberdevices.ru/help/tv`.
- На 4PDA в теме «Sber линейка Line S» (t=1088938) встречаются сообщения про «рут через usb adb» и «мод прошивку SDX-55U4139», но **проверяемого способа нет**, это на свой риск.

Поэтому сделан практичный вариант: **Free My TV вместо лаунчера Сбера + отключение мусора + блокировка автообновлений**. Это ровно тот «чистый ТВ», которого можно достичь без паяльника.

Если всё же захочется экспериментировать с root/прошивкой — сначала нужен **сервисный дамп именно этой платы** (для отката), и лучше это делать не на единственном телевизоре.

## 8. Про запрос «Разрешить отладку по USB?» — что сделано

Причина: в Android 13 при `ro.adb.secure=1` и залоченном загрузчике (`green`) adbd **обязан** спросить разрешение у каждого нового ключа. Отключить саму проверку можно только правкой прошивки (root), а ключи лежат в `/data/misc/adb/adb_keys` — туда без root не записать.

Что сделано:
- Ключ **этого компьютера** принят с галочкой «Всегда разрешать отладку с этого компьютера» — проверено двумя перезагрузками: ТВ подключается по `adb connect <IP-ТВ>:5555` без запроса.
- Ключ самого **Free My TV** (он ходит по ADB на `127.0.0.1:5555`, чтобы переключать главный экран/заставку) тоже принят с «Всегда разрешать» — после перезагрузок ТВ не спрашивает.
- Ключи в Android **не стираются при перезагрузке** (прошивка Сбера их не чистит — проверено).

Когда запрос может появиться снова:
1. Подключаетесь **с другого компьютера/телефона** (у каждого свой ключ) — один раз нажать «Разрешить» с галочкой.
2. Ставите новую программу, которая сама лезет в ADB (её ключ — новый).
3. Сброс ТВ к заводским настройкам — ключи стираются.

Совсем убрать запрос без root нельзя; **с root** — да (`ro.adb.secure=0` / запись ключей в `adb_keys`), но root на этой прошивке публично не получен. Поэтому на практике: один раз «Всегда разрешать» на устройство — и больше не спрашивает.

## 9. Как всё откатить (если захотите вернуть как было)

Приложения Сбера удалены для пользователя, поэтому «включить» их уже нельзя — можно только восстановить системные (APK которых остался в `/vendor`/`/system`) командой `install-existing`. Приложения из `/data` (магазин, музыка, видео и т.п.) вернутся только сбросом ТВ.

```powershell
$adb = "%USERPROFILE%\dsh-tv-build\platform-tools\adb.exe"
& $adb connect <IP-ТВ>:5555

# 1) остановить сторожа, иначе он снова всё удалит
& $adb shell pm disable-user --user 0 io.sberstop

# 2) вернуть то, что осталось в системе (системные разделы)
$pkgs = @("ru.sberdevices.starlauncher","ru.sberdevices.app.setup","ru.sberdevices.bugreporter",
          "ru.sberdevices.videos","ru.sberdevices.starscreensaver")
foreach ($p in $pkgs) { & $adb shell "cmd package install-existing --user 0 $p" }

# 3) вернуть лаунчер Сбера главным экраном и его заставку
& $adb shell "cmd package set-home-activity 'ru.sberdevices.starlauncher/.ui.mainscreen.MainActivity'"
& $adb shell "settings put secure screensaver_components 'ru.sberdevices.starscreensaver/ru.sberdevices.starscreensaver.StarScreenSaverService'"

# 4) вернуть рекламу/обновления/DPI-ускоритель
& $adb shell "appops set ru.sberdevices.services SYSTEM_ALERT_WINDOW allow"
& $adb shell "settings put global ota_disable_automatic_update 0"
& $adb shell "settings put global auto_update_apps 1"
& $adb shell "pm enable org.nodpi.hello"      # NoDPI: включить обратно (можно и не включать)

# 5) снять Free My TV / SmartTube, если больше не нужны
& $adb uninstall org.smarttube.stable
& $adb uninstall io.freemytv
```

**Самый полный откат — сброс ТВ к заводским настройкам**: вернётся всё, включая удалённые приложения Сбера, но придётся заново всё настраивать (и снова придут автообновления/реклама).

**Про кнопку «Главный экран → Заводской» в Free My TV:** теперь она **не сработает** — лаунчер Сбера удалён, возвращать «Заводской» больше некуда (Free My TV сообщит об ошибке и останется на месте). Это нормально: путь назад — только сброс ТВ.

Полезные команды:

```powershell
$adb = "%USERPROFILE%\dsh-tv-build\platform-tools\adb.exe"
```
